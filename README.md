🧟 Left 4 Dead 2 Launcher for Android

A custom Android launcher for Left 4 Dead 2, designed to provide a dedicated mobile gaming experience with GPU configuration, video settings, control options, mod management, and a personalized interface inspired by the zombie-apocalypse atmosphere of the game.

✨ Features

🎮 Game Launcher

- Dedicated launcher interface for Left 4 Dead 2.
- Customized startup screen and game status text.
- Personalized game banner.
- Integrated game launch workflow.

⚙️ Installation and Graphics Configuration

- Advanced settings for configuring the graphics system.
- Graphics options intended to accommodate different GPU architectures and device performance levels.
- Ability to select a graphics system and adjust the configuration according to your device's hardware capabilities.
- Configuration options should be selected according to the device's GPU and compatibility.

Important: The best configuration depends on the device, GPU, graphics drivers, and selected rendering system. Not every configuration is suitable for every device.

🎥 Video Settings

- Video configuration options for adjusting the game's graphical experience.
- Intended to help users find a balance between visual quality, performance, and stability.
- Available options may vary depending on the selected graphics system and device compatibility.

🎮 Controls

- Dedicated controls configuration option.
- Access to the game's available control settings.
- Intended to make control customization easier for mobile gameplay.

🧩 Mod System

- Integrated Mods section in the launcher.
- Dedicated interface for accessing available game modifications.
- Mod compatibility depends on the individual mod and game configuration.

🌐 Online Mode

- Dedicated Online section.
- Player configuration options are part of the intended functionality.

Status: Experimental

- Online connection through the launcher has not yet been verified successfully.
- Server functionality is available, but launcher connectivity still requires testing.

🌍 Language Selection

- Language selection option available in the launcher.
- Intended to configure the game's language.

Status: Unverified

- Language switching has not been fully tested.
- Specific game files or configuration data may be required.
- Not every language is guaranteed to work.

🗺️ Chapter Selection

- Dedicated interface for navigating the game's chapters.
- Intended to allow users to select a chapter and launch it directly.

Status: Incomplete

- Direct chapter launching is not yet configured correctly.
- Selecting a chapter does not guarantee that the game will start on the selected map.
- The chapter-selection workflow requires further investigation and testing.

📊 Performance Monitoring

- Existing in-game FPS monitoring system.
- FPS measurement while the monitor is enabled.
- Graphics diagnostics for investigating rendering behavior and performance issues.
- Further optimization planned.

🔔 Game Notifications

- Personalized Left 4 Dead 2 notification.
- Custom game-running status text.
- Dedicated notification icon and channel.

📱 Device Compatibility and Testing

The project has also been tested on a Red Magic 8 Pro.

The main development target is the Redmi Note 13 Pro 5G, featuring:

- Qualcomm Snapdragon 7s Gen 2.
- Adreno 710 GPU.
- Android 15.

Testing on these devices does not guarantee compatibility with every Android device or graphics configuration.
